# Package contents

This inventory describes the supplied local material. User-generated logs and backups are not pre-populated. Docker Compose builds the course image from the separately fetched PostgreSQL base image.

## Reading and execution order

[Start here](docs/00_start_here.md), follow [the course map](docs/01_course_map.md), then use [the capstone](docs/capstone/README.md). See [validation status](VALIDATION.md) before interpreting test claims.
